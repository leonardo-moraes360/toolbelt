## New problems

1. **P1 — MCP graph ignores already-indexed graph without `TB_GRAPH=on`**  
   - Repro: `tb graph --enable rebuild` in the repo; `printf '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"tb_graph_search","arguments":{"query":"TagSet"}}}\n' \| tb mcp` → “grafo desabilitado”. With `TB_GRAPH=on` it works.  
   - Expected: use existing `.toolbelt/graph.json` or mirror `--enable`.  
   - Actual: gate only by env, independent of on-disk index.

2. **P2 — Output flag inconsistency (`verify -o` vs `review --output`)**  
   - Repro: `tb review ... -o /tmp/x.json` → `unknown shorthand flag: 'o'`.  
   - Expected: same UX across Phase 2 subcommands.  
   - Actual: verify has `-o`; review/drift only `--output`.

3. **P2 — `graph callers`/`deps` of little use on a real Go target**  
   - Repro: after rebuild, `tb graph --enable callers --function Map` and `deps --module metrics.TagSet` → empty output, even though `search TagSet` finds symbols.  
   - Expected: callers of `TagSet.Map` / type deps.  
   - Actual: limited impact for fine navigation.

4. **P3 — `tb init` does not integrate pre-existing AI instrumentation**  
   - Repro: repo with `AGENTS.md`/`CLAUDE.md`; `tb init` only creates default config.  
   - Expected (docs/research): import build/test rules from AGENTS into `verify.*` and invariants.  
   - Actual: AGENTS only enters the graph as indexed markdown; mem/verify/config do not consume it.

## What tb caught and what it let slip

**Caught**
- Ticket scope aligned with the diff (clean `drift` / `review.drift`).
- Location of `TagSet` / `MapTagSet` via `graph search` (useful for the issue).
- Aborting verify when touching `.toolbelt/thresholds.yaml` (hardcoded protected path).
- Integrity of the invariants file (`mem check`).

**Let slip**
- Build error outside `test_cmd` (verify PASS with a tree that does not compile).
- Textual mention of `tests/hidden` treated as a violation (false positive), while omission of migrating `MapTagSet` was not signaled (completeness false negative).
- Operator `guard.yaml` with no effect.
- Completeness of issue #2764 (public API ok; adoption in Prometheus RW consumer and note about `Map` not covered).
- Lint and full k6 suite (not orchestrated by default; local config pointed only at `./metrics/`).

## Interaction with existing instrumentation / onboarding

- k6 already has `AGENTS.md` (+ `CLAUDE.md` symlink) with canonical commands (`make build/tests/lint/check`), architecture, and git rules.
- `tb init` **does not read** those files; creates generic `.toolbelt/config.yaml` (`go test ./...` / `go test ./tests/hidden/...`).
- Manual adjustment: `verify.test_cmd: go test ./metrics/ -count=1` (full suite would be the AGENTS one, not tb’s default).
- `tb graph` **indexes** `AGENTS.md` as document/sections (appears in `graph.json`), but that does not become mandate/invariants or verify commands.
- `tb mem init` injects generic anti-cheat invariants that do **not** come from AGENTS; possible conceptual duplication (project test rules vs tb rules) without merge.
- Potential conflict: AGENTS forbids `git reset --hard` / force-push; the study flow used local reset for probes — tb does not alert about AGENTS policies.
- What tb should import: AGENTS build/test/lint blocks → `verify.test_cmd` / check script; git restrictions and “all new code should have tests” → invariants; key-package map → `graph` seeds / ticket scope.

## Improvement suggestions

1. **[P0][verify]** Accept a multi-command pipeline (test + `go build` + lint) or `check_cmd` mirroring `make check`; fail if the module binary does not compile.  
2. **[P0][guard]** Actually load `.toolbelt/guard.yaml`; document remaining hardcoded paths.  
3. **[P1][review]** Match invariants by touched path / AST, not substring in the diff (eliminate `tests/hidden` FP).  
4. **[P1][review/verify]** Completeness rule: obvious consumers (`graph search` hits on the same symbol) and ticket acceptance checklist.  
5. **[P1][bench]** Honor `default_agent`; add `--agent` to `bench compare`; make clear that `--fake` without `--fake-config` does not implement fixtures.  
6. **[P1][mcp/graph]** If `graph.json` exists, enable MCP tools without requiring `TB_GRAPH=on` (or document/warn on `tools/call`).  
7. **[P1][docs/cli]** Sync `docs/cli.md` with real Cobra (`mem add`, graph/review flags).  
8. **[P2][init/mem]** Onboarding: detect `AGENTS.md`/`CLAUDE.md` and propose import into verify + invariants.  
9. **[P2][verify/visual]** Propagate `skipped=true` in the report when all screens skip.  
10. **[P2][cli]** Unify `-o`/`--output`; emit version ldflags on `go install` or document `make build`/`make install`.  
11. **[P3][config]** Revisit mode `0600` vs dirs `0755` (CI sharing).  
12. **[P3][graph]** Improve Go method resolution in `callers`/`deps` (`pkg.Type.Method` qualification).
