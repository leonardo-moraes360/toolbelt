## Problems that persist

From [round 1](../k6.md) / checklist, still observed in this run:

1. **MCP graph requires `TB_GRAPH=on`** even with indexed `.toolbelt/graph.json` → `grafo desabilitado` without the env.
2. **Misaligned CLI docs** (`mem add --type/--title`, `review -o`).
3. **Config mode `0600`** on `.toolbelt/config.yaml` / seeded `AGENTS.md`.
4. **`tb init` does not apply** AGENTS commands (`make tests` / `make lint`) to `verify.*` — only records hints.
5. **Weak qualitative completeness**: review does not require a real `WithField` consumer (only a generic acceptance warning).
6. **k6 lint and `-race` suite** outside the default flow (agent still must point cmds manually).

## Improvement suggestions

1. **[P1][init/verify]** Map AGENTS hints (`make tests`/`make lint`/`make build`) → `verify.test_cmd`/`lint_cmd`/`build_cmd` with a confirmation prompt.  
2. **[P1][mcp/graph]** If `graph.json` exists, enable MCP tools without requiring `TB_GRAPH=on` (or a `tools/call` message pointing at the file).  
3. **[P2][graph]** Detect symlink root and `EvalSymlinks` / warn before writing an empty index.  
4. **[P2][verify/guard]** “Dev” mode: do not abort verify on `guard.yaml` `protected_paths` that are in the ticket scope (keep abort only for hardcoded anti-cheat).  
5. **[P2][docs/cli]** Remove `mem add --type/--title` examples; unify `-o`/`--output` on review/drift.  
6. **[P3][review]** Completeness: if graph search finds only the new definition without external callers, suggest adoption or mark acceptance explicitly.
